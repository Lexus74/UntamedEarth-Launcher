# Untamed Earth — Player Launcher

[Download the Windows launcher](https://github.com/Lexus74/UntamedEarth-Launcher/releases/latest/download/UntamedEarthLauncher.exe)

This repository contains only the small launcher and its documentation. Game files, accounts and access restrictions remain private.

Enter the username, password and invitation key sent by the developer. The launcher verifies access before downloading game files. Returning players sign in to check for updates.

Windows 10/11; .NET Framework required. The private alpha is solo. This early launcher is unsigned. If the home service is offline, new downloads are unavailable. No GitHub login is required for players.

The developer never asks for your Gmail app password or GitHub token. Keep your game invitation and password private.
